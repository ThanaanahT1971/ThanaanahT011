แพลตฟอร์มระบบสอบภาษาอังกฤษออนไลน์

ระบบการวัดและประเมินผลทักษะภาษาอังกฤษแบบครบวงจรสำหรับครูและนักเรียน ออกแบบข้อสอบไวยากรณ์ คำศัพท์ และการอ่าน พร้อมระบบจับเวลาอัตโนมัติ การตรวจคะแนนทันที และการวิเคราะห์ผลสัมฤทธิ์

👨‍🏫

แดชบอร์ดคุณครู (Teacher Dashboard)

สร้างข้อสอบภาษาอังกฤษ จัดการคลังคำถาม ตรวจสอบผลคะแนนนักเรียน และดูสถิติวิเคราะห์ผลสัมฤทธิ์ทางการเรียนอย่างละเอียด

  • ✓ ระบบสร้างข้อสอบปรนัย (4 ตัวเลือก) แบบไดนามิก
  • ✓ คลังข้อสอบแยกตามหมวดหมู่ นำกลับมาใช้ซ้ำได้
  • ✓ กราฟการกระจายคะแนน & ส่งออกไฟล์ CSV
  • ✓ กำหนดรหัสเข้าสอบ (Access Code) และเผยแพร่ทันที

พอร์ทัลนักเรียน (Student Portal)

กรอกรหัสข้อสอบเพื่อเริ่มทำแบบทดสอบ มีนาฬิกานับเวลาถอยหลัง ส่งข้อสอบ และตรวจดูผลคะแนนพร้อมเฉลยคำอธิบายได้ทันที

  • ✓ หน้าต่างทำข้อสอบที่สะอาด สบายตา ไร้สิ่งรบกวน
  • ✓ นาฬิกานับถอยหลังแบบเรียลไทม์ พร้อมระบบส่งอัตโนมัติเมื่อหมดเวลา
  • ✓ แผงเลือกข้อสอบเพื่อดูข้อที่ตอบแล้วและยังไม่ได้ตอบ
  • ✓ ดูคะแนน เกรด และคำอธิบายเฉลยอย่างละเอียด

การจัดการข้อมูลสาธิต (Demonstration Data)

ระบบ EXAMFORGE จัดเก็บข้อสอบ คลังคำถาม และประวัติการสอบทั้งหมดไว้ใน localStorage ของเบราว์เซอร์ คุณสามารถคืนค่าเป็นชุดข้อมูลตัวอย่างเริ่มต้นมาตรฐานได้ทุกเมื่อ

🚀 สำหรับการนำขึ้น GitHub & GitHub Pages

หากต้องการนำโค้ดไปใส่ใน GitHub แบบง่ายที่สุดโดยใช้ ไฟล์เดียวจบ:

  1. คลิกปุ่ม "ดาวน์โหลดไฟล์ HTML เดี่ยวสำหรับ GitHub" ด้านบน คุณจะได้ไฟล์ชื่อ index.html
  2. สร้าง Repository ใหม่บน GitHub
  3. อัปโหลดไฟล์ index.html นี้ขึ้นไปใน Repository
  4. ไปที่ Settings > Pages > Branch เลือก main แล้วกด Save คุณจะได้เว็บไซต์ออนไลน์จริงทันที!

โครงสร้างสถาปัตยกรรมต้นแบบเพื่อการเรียนรู้

• เทคโนโลยีที่ใช้: พัฒนาด้วย Semantic HTML5, CSS3 และ Vanilla JavaScript แท้ เพื่อให้โค้ดเรียบง่ายและเข้าใจง่ายสำหรับผู้เริ่มต้น
• ความปลอดภัยในการตรวจข้อสอบ: ในเวอร์ชันต้นแบบนี้ การตรวจข้อสอบประมวลผลบนฝั่งเบราว์เซอร์ สำหรับระบบจริงในระดับโปรดักชันควรตรวจผ่านเซิร์ฟเวอร์หลังบ้าน (Backend Server)
• การบันทึกข้อมูล: บันทึกลงหน่วยความจำเบราว์เซอร์ (Browser LocalStorage) ทำให้ข้อมูลไม่สูญหายแม้กดรีเฟรชหน้าเว็บ
